# SOC L1 - Security Alert Investigation

## Project Overview
This project demonstrates a basic SOC Level 1 investigation of suspicious login activity.

## Scenario
Multiple failed login attempts were detected on a user account, which may indicate a Brute Force attack.

## Investigation Steps
1. Review the security alert.
2. Analyze login logs.
3. Identify the source IP address.
4. Check the affected user account.
5. Assess the risk and severity.
6. Determine whether the alert is a True Positive or False Positive.
7. Escalate the incident if necessary.

## Tools
- SIEM (Splunk)
- Windows Security Logs
- MITRE ATT&CK

## Expected Outcome
Understand how a SOC L1 analyst investigates suspicious login activity, evaluates risks, and documents security incidents.

## Disclaimer
This project uses simulated data for educational purposes only.
